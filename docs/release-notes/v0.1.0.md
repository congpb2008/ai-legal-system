# Legal Knowledge Platform — v0.1.0 Release Notes

**Release date:** 2026-08-08
**Version:** 0.1.0

---

## Overview

This is the initial MVP release of the Legal Knowledge Platform — an AI-powered system that transforms legal documents into structured knowledge and provides evidence-grounded, traceable answers.

The platform accepts PDF and DOCX uploads, parses documents into a structured Knowledge Tree, performs hybrid (keyword + semantic) retrieval, and generates answers with verifiable citations. It enforces vault-based document isolation and access control.

**Primary language:** Vietnamese (vi) — optimized for Vietnamese legal documents.

---

## What's Included

### Core Capabilities

- **Document upload** — PDF (digital and scanned) and DOCX with MIME validation, SHA-256 checksum dedup, 100 MB limit
- **OCR** — digital text extraction (PyMuPDF) and scanned-page OCR (Tesseract)
- **Document parsing** — structure detection (Chapters, Sections, Articles, Clauses, Points, Appendices, Tables, Figures)
- **Knowledge Tree** — canonical, immutable structured representation with source traceability
- **Hybrid search** — keyword + semantic retrieval with Reciprocal Rank Fusion
- **Reranking** — evidence scoring, deduplication, diversity optimization
- **Answer generation** — template-based, evidence-grounded, with confidence reporting
- **Citation builder** — claim detection, evidence mapping, citation resolution
- **Vault isolation** — 4 vault types (Common, Department, Project, Personal) with RBAC

### User Interface

- 7-page Web UI (Home, Search, Ask, Vaults, Documents, Upload, Admin)
- Vietnamese language interface
- Responsive layout (desktop, tablet, mobile)
- Light/dark/high-contrast themes
- Keyboard-accessible controls

### API

- 28 REST endpoints across 8 domains
- Bearer token authentication
- Standardized JSON error schema
- Full API documentation

### Operations

- Structured JSON logging
- Health/readiness/liveness endpoints
- Metrics (counters, gauges, histograms)
- Job monitoring
- Evaluation platform with IR metrics

## Installation

### Prerequisites

- Python 3.12 or newer
- 2 GB RAM (4 GB recommended)
- 500 MB disk space

### Install

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

To also install test tooling:

```bash
pip install -e ".[test]"
```

### Start

```bash
legal-platform
```

Or equivalently:

```bash
python -m legal_platform
```

The server starts on `http://0.0.0.0:8080`. Open `http://localhost:8080` in your browser.

### First Steps

1. Log in with any username and password
2. Create a vault (**📁 Kho tài liệu** → **+ Tạo mới**)
3. Upload a document (**📤 Tải lên**)
4. Search (**🔍 Tra cứu**) or ask a question (**❓ Hỏi đáp**)

## Known Limitations

| Limitation | Impact |
|------------|--------|
| Automated processing pipeline not triggered after upload | Documents are registered but may not be searchable until manually processed via the Admin panel |
| In-memory storage by default | All data lost when server stops |
| No LLM integration | Template-based answers (no natural language generation) |
| No conversation memory | Each question is independent |
| Placeholder embedding engine | Semantic search quality is limited |
| No real authentication | Any non-empty credentials accepted |
| No TLS/HTTPS | Plain HTTP traffic |
| No rate limiting | No abuse protection |
| No backup/restore automation | Manual file copying only |
| No `.gitignore` | Risk of committing secrets |
